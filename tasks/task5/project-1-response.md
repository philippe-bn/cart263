# *Nou Noune's Class Notes* by Amélie Barrette
> This project is a summary of Amélie's (or Nou Noune's) class notes, with new examples of what we have seen in the scope of CART 263.
> I was surprised by this approach, as I did not think that this was something we could do, but quickly it won me over.
> Nou Noune's work brings new life into the building blocks of the course, showing us what can be made quickly and easily with these techniques.
> Their ability to communicate clearly and effectively what each chapter consists of impressed me. I found the project easy to understand while retaining complexity.
> I would love to see what Nou Noune does next with these blocks, and this seems to me to have been a great way to review the material before heading off into their next project.

# *Survive the Depths* by Benjamin Macknofsky
> Ben's project is a web game, which consists of trying to survive as bait on a fishing hook.
> The dynamics are quite easy for the player to understand from the start, with basic dynamics like shooting at enemies (fish) and avoiding shooting at bombs.
> The aesthetic of the game specifically caught my eye, with a heightened level of attention to detail.
> Ben introduces moving algae, currents, and even debris(?) which makes for a beautiful setting and a peaceful experience (despite the anxiety induced by fish growing larger and larger and the player's struggle to get them all).
> The GUI is the only part that I found was not obvious for the player to interact with, although it is very legible and accessible.
> I was particularly impressed by the particles that appear when an enemy is shot - again, the attention to detail is notable.
> Ben's code is clean, and makes effective use of OOP principles.

# *Interactive Bike Garage* by Émile Bédard
> Émile's project is a web experience/service for bikers to record their bikes and bike parts, and easily access information pertaining to bike repairs.
> Émile makes witty use of CSS transforms for animation, and addressing these in the Javascript file was very interesting to me.
> The combination of assets created in Illustrator with HTML, CSS and Javascript is at the heart of the project: he masterfully combines techniques to quickly create a clear and concise user interface which is both aesthetically pleasing and easy to navigate.
> I was surprised by the brevity of the Javascript code used in this project, but it is not inherently a downside to the quality of the work. I think this project makes a strong case for using the DOM as a way to locally store information, and it makes sense for that to remain the focus of it.
> I can absolutely see the use cases for this project, and I am impressed at how Émile came up with a project that can have real-world applications and that offers a real solutions for his community. It is entirely in his honor.
